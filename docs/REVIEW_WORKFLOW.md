# Review Workflow

Current review workflow is cloud UI first, with local CLI fallback.

## Canonical Flow

1. Process one scene/job.
2. Open completed scene review.
3. Inspect contact sheet and cover set.
4. Approve/adjust selection manually.
5. Keep explicit operator approval before any external publication step.

## Scope Boundaries

- This workflow does not auto-publish to platforms.
- Quality decisions are visual and human-led.
- Decision logs are supporting evidence, not sole quality truth.

## Data Artifacts

- scene outputs (covers/contact sheet)
- decision logs
- review decisions captured by current UI/CLI path in repo code
